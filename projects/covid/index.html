COVID-19 Data Platform in Metallurgical Plants

At the beginning of COVID-19 pandemic, the occupational medicine team at a large metallurgical company needed a scalable system to replace the Excel spreadsheet they started for tracking. Collaborating with the chief doctor, I defined the data requirements and built a Python CRUD web platform using Flask, where doctors could input and update data into a database. I also created a pipeline to collect and clean data from states health agencies using public APIs.

To further support the doctors, I developed a Tableau dashboard integrating both private and public data, offering insights into COVID-19 rates, testing efforts, and trends across factories. This tool allowed the team to compare company data with city-level statistics, allocate resources like testing kits and safety equipment, and manage factory operations more effectively. The dashboard quickly became essential for their daily operations, earning high praise from the medical team.
